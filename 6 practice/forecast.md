# Прогноз до сравнения моделей

Составлен после измерения компонентов последовательной нагрузки, до запуска `--stage benchmark`.

Ожидается: один документ быстрее обрабатывается последовательно, поскольку холодный процессный пул дороже единицы работы. Для средних наборов потоки перекроют ожидания. На большом наборе процессы смогут параллельно выполнять и вычисления; asyncio + процессы может выиграть за счёт перекрытия ожиданий, но потребует сериализации текстов и планирования отдельных задач. Между двумя последними моделями уверенного победителя до замеров нет.

Для потоков условная оценка Амдала использует f = доля генерации, вычислений и редукции. Она моделирует неперекрывающиеся фазы CPU и ожиданий и не является строгой границей для конвейера, где CPU одной задачи перекрывается с ожиданием другой. Для процессов f = доля редукции; это оптимистическая оценка без запуска пула, передачи данных и ограничений планировщика.
